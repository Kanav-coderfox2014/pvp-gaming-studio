NEON FIGHTERS — README

ABOUT THE GAME
Neon Fighters is a 2D fighting game where you battle against computer-controlled fighters. Choose your difficulty level, fight on platforms, block attacks, jump, and try to win!

HOW TO START

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in your browser, or run it using the Live Server extension.
3. Click the PLAY button on the website to start the game.
4. Select your preferred difficulty and get ready to fight!

DIFFICULTY LEVELS

* EASY: Fight against one weaker CPU fighter.
* MEDIUM: Fight against a more challenging CPU fighter.
* HARD: Fight against a faster and smarter CPU fighter.
* VERY HARD: Fight against three CPU fighters at once. Watch all three CPU health bars!

CONTROLS

* LEFT ARROW: Move left.
* RIGHT ARROW: Move right.
* UP ARROW: Jump.
* SPACE: Punch.
* F: Kick.
* D: Block.

GAME FEATURES

* Colourful neon-inspired design.
* Player and CPU health bars.
* Three separate CPU health bars in Very Hard mode.
* Platforms that fighters can jump onto.
* Blocking prevents damage while active.
* Fullscreen gameplay.
* Win and lose screens with the option to return to the main menu.
* Choose when to start another game.

RETURNING TO THE MENU
When the match ends, click GO TO MENU to leave fullscreen mode and return to the normal website. From there, click PLAY to begin another game.

PROJECT FILES

* `index.html` — Website structure.
* `css/style.css` — Colours, layout, and visual design.
* `js/game.js` — Game controls, movement, combat, CPU behaviour, and scoring.
* `assets/` — Folder for images, sounds, and other game assets.

Have fun playing Neon Fighters!

Created as a browser-based game project.
